# コミチ ミッション自動化 (Comici Mission Automator)

コミチ系プラットフォーム（comicpash.jp, comicride.jp などのマンガサイト）の無料チケット取得ミッションとガチャを、全自動で消化するためのChrome拡張機能です。

## ✨ 主な機能

- **ミッションの自動解析**
  対象サイトの `/mission` ページで実行するだけで、現在未完了のミッションを自動的にピックアップし、最適な順序で実行キューに登録します。
- **完全自動の「読了」処理 (縦読み・横読み対応)**
  対象のエピソードを開き、人間の操作をシミュレート（シークバーのスライドやページごとのスクロール）することで、確実に「読了」判定を獲得します。横読みビューアー・縦読みビューアーの双方に自動対応しています。
- **お気に入りミッションの自動化**
  「お気に入りに追加する」ミッションに対しては、対象作品をお気に入り登録したのち、自動で即座に登録を解除します。普段の本棚を汚すことなくミッション報酬だけを獲得できます。
- **外部サイト連携ミッション対応**
  他サイトへの遷移を伴うエピソード読了ミッションも、別タブで自動展開し追跡・完了させます。
- **ガチャの自動実行**
  すべての読了ミッションをこなした後、無料ガチャを自動で回します。X (旧Twitter) へのシェアによる「もう1回まわす」機能にも対応し、シェア画面を自動で処理して再挑戦します。

## 🎯 使い方 (UX)

非常にシンプルで直感的な操作で、日々のミッション消化を終わらせることができます。

1. **ミッションページを開く**
   対象のコミチ系マンガサイトのミッションページ（例: `https://example.com/mission`）をブラウザで開きます。
2. **拡張機能を起動**
   Chromeのツールバーから「コミチ ミッション自動化」のアイコンをクリックし、ポップアップを開きます。
3. **ボタンを1クリックするだけ**
   「**一括自動実行を開始**」ボタンをクリックします。
   *※実行中はポップアップ内のログウィンドウに「○話読了中...」「ガチャ完了」などのステータスがリアルタイムで表示されます。*
4. **自動で完了**
   拡張機能が自動的に対象のマンガを開き、スクロールやページ送りを進めます。すべてのミッションとガチャが終了すると、自動的に最初のミッションページに戻ります。

> **💡 ヒント:** 
> 処理を途中でやめたい場合は、ポップアップを開いて停止ボタン（実行中に切り替わります）を押すか、自動で動いているタブを閉じてください。

## 🛠 インストール方法

本拡張機能はChromeウェブストアには公開されていないため、以下の手順で手動インストールしてください。

1. このプロジェクトのフォルダをPCの任意の場所に保存します。
2. Google Chromeを開き、URLバーに `chrome://extensions/` と入力して拡張機能の管理画面を開きます。
3. 画面右上にある **「デベロッパー モード」** のスイッチをオンにします。
4. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. 保存したプロジェクトのフォルダ（`manifest.json` が含まれているフォルダ）を選択します。
6. 拡張機能が読み込まれ、ツールバーにアイコンが追加されたら準備完了です！

## 📁 内部構成について

本拡張機能は、ブラウザの負荷を最小限に抑えつつ確実な動作を行うため、以下の技術構成を採用しています。

- `manifest.json`: Manifest V3 対応。Chrome Debugger API (`chrome.debugger`) へのアクセス権を含みます。
- `background.js`: メインの司令塔。タブの遷移、タスクキューの管理、Debugger APIを利用したフォールバック用のキー入力やクリックを制御します。
- `content_mission.js`: ミッション一覧ページから、各ミッションの進捗（X話/Y話）や種類を解析・抽出します。
- `content_action.js`: 実際のビューアーページに注入され、DOMを解析してシークバー操作や縦スクロールを実行。完了状態（次話ボタン出現など）を検知します。
- `popup.html` / `popup.js`: ダークモードベースのモダンで分かりやすいユーザーインターフェースを提供します。
